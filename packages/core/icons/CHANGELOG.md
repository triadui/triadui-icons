# @triadui/icons - Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

- Initial release with support for Material Icons

- Documentation and examples

- Updated package dependencies to latest stable versions
- Enhanced build configuration for cross-environment compatibility

### Added
- Support for Next.js App Router and Pages Router
- Vite and Create React App examples
- Comprehensive documentation
- JavaScript usage examples

### Changed
- Updated package exports for better module resolution
- Improved TypeScript type definitions
- Enhanced build process with multiple output formats
